Ghost-OS: Secret Agent Hacker Terminal

A retro green-screen hacker terminal with falling matrix code, fake hack tools, sound effects, and a hidden cipher mini-game. It is a single index.html file with no dependencies.

How to Play
Type help in the terminal to see the commands.
Run scan, crack or satellite (or click the buttons) and watch the progress bar.
Crack the cipher challenge: every letter in the scrambled word is shifted by a secret number. Type solve WORD to answer, or hint for the first letter.
Use the Sound button to mute the beeps.
Secret Features
Score 30 points in the cipher game to unlock a hidden file.
Type matrix to see a message from the Matrix.
Every finished hack shakes the screen.
Built With

HTML, CSS, JavaScript, the Canvas API and the Web Audio API. Includes console.assert tests for the cipher and progress logic.
